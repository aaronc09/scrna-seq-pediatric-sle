# Original preprocessing and annotation evidence

These files preserve the original preprocessing, cluster labels, exclusion lists, and cell counts. They are historical evidence and inputs to the reproducibility checks; original retained counts here are not the revised-primary counts.

Current exact labels and donor accounting are in `../revised_primary/*_primary_cell_labels.csv.gz` and `../revised_primary/qc/`. The supporting revision review is in `../annotation_review/`.
