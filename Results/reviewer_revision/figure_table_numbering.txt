FIGURE AND TABLE NUMBERING

The manuscript contains Figures 1-5 and main Tables 1-2; supporting data are numbered Supplemental Tables S1-S9. Supplemental Tables S1-S9 remain supporting data files rather than thousands of rows embedded in the manuscript. A combined numbered table may have panels stored in separate files. Existing scientific filenames are preserved to keep scripts and links working. Numerical values are unchanged.

FIGURES

Figure 1. Cell-type annotation of the pediatric and adult cohorts. Cohort-specific UMAP coordinates show the 298,610 retained cells. Coordinates were calculated before the targeted T-cell classification and were not refitted. Unresolved cells and red-blood-cell/platelet clusters are omitted. Panel A shows the pediatric cohort and panel B the adult cohort. Matching colors represent the same cell types. Cohorts were processed independently, so coordinates should be interpreted within each panel rather than as shared spatial coordinates. cDC, conventional dendritic cell; IFN, interferon; NK, natural killer; pDC, plasmacytoid dendritic cell; UMAP, uniform manifold approximation and projection.
  Results/manuscript_figures/figure1_pediatric_adult_celltype_umap.png

Figure 2. Primary cohort-by-SLE test. Red points meet FDR < 0.05; the dashed horizontal line marks that threshold. The volcano plot shows 2,335 estimable tests; 220 meet FDR < 0.05. The coefficient is (pediatric SLE - pediatric healthy) - (adult SLE - adult healthy), in relative rank-score units.
  Results/manuscript_figures/figure2_primary_analysis.png
  Vector version: Results/manuscript_figures/figure2_primary_analysis.svg

Figure 3. All-donor versus female-only coefficient comparison, r=0.994. Blue points are significant in the primary analysis; gray points are the other shared tests. The dashed line marks equal coefficients. Coefficients are in relative rank-score units.
  Results/manuscript_figures/figure3_female_only_comparison.png
  Vector version: Results/manuscript_figures/figure3_female_only_comparison.svg

Figure 4. Individual donor relative rank scores for the four illustrative combinations in Table 2. Each point is one contributing donor; horizontal bars show group means. Contributing donor scores are provided in Supplemental Table S9A, and group-specific counts appear in Table 2B.
  Results/manuscript_figures/figure4_individual_donor_scores.png
  Vector version: Results/manuscript_figures/figure4_individual_donor_scores.svg

Figure 5. The four Table 2 combinations among pediatric SLE donors, separated by technical batch. Points represent donors and bars show batch means. Batch tests are provided in Supplemental Table S8C, with BH adjustment across the full seven-combination diagnostic family.
  Results/manuscript_figures/figure5_pediatric_SLE_by_batch.png
  Vector version: Results/manuscript_figures/figure5_pediatric_SLE_by_batch.svg
