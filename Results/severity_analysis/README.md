# Original-exclusion analysis and source metadata

Clinical metadata here remain inputs to the current analysis. Model and significant-interaction files in this directory retain the original full-cluster exclusions, including the original 2,527-test, 123-significant-interaction analysis. They are preserved for reproduction and comparison.

The current primary model is `../revised_primary/primary_models.csv` (2,374 tests, 171 significant interactions). Use `../revised_primary/README.md` for current manuscript outputs and reproduction instructions. Secondary severity analyses here have not been recomputed with revised annotations and are not reported as revised-primary findings.
